Each player's information key stores the complete sequence of public moves, observed opponent fog events, and that player's own fog choices and success/failure observations. WHY “MIXED” HAS TWO MEANINGS HERE

Softmax randomness is not an equilibrium. MCCFR mixing is a behavioral strategy.

Heuristic mix

σ(a|I) ∝ exp(β Q(I,a))

Softmax turns action scores into probabilities. It is useful for bounded-rational play and exploration, but the probabilities are not chosen to prevent exploitation by a strategic opponent.

Equilibrium behavior

σ̄ᵢ(a|I) ← average policy from MCCFR

Outcome-sampling MCCFR updates counterfactual regrets with importance weighting. In finite two-player zero-sum perfect-recall games, the time-averaged regret-minimizing strategy approaches a Nash equilibrium.

CORRECTNESS AUDIT

What is exact, what is approximate, and what is only a benchmark.

Exact game transitionsHidden attempts remain legal after an opponent claim, failed attempts consume a turn, and terminal outcomes use the true board.
Exact information legalityThe engine asserts that all histories sharing an information key expose the same legal action set.
Exact zero-sum utilityTerminal utility is +1 / 0 / −1 for the acting root player, with the opponent receiving the negation.
Approximate equilibriumMCCFR is theoretically convergent, but any finite browser training run is an approximation and is labeled as such.
Heuristic belief valuesBelief Search, Softmax, Robust, and Thompson use equal-weight possible histories and a perfect-information continuation oracle.
Oracle is intentionally illegalThe omniscient strategy sees the true hidden state and exists only as a simulation upper benchmark.

RULES OF THE FOG

Tic-tac-toe where action history matters.

The true board determines wins. Information determines decisions.

01

Choose mystery cells

Before the match, select at least two fog cells. Both players know which locations are mysterious.

02

Visible moves are public

A move on a normal cell is observed by both players and behaves like ordinary tic-tac-toe.

03

Fog actions hide location

The opponent learns that a fog action happened, but not which mystery cell was attempted.

04

First claim owns the cell

If the mystery cell is empty, the acting player claims it. If it was already claimed, the attempt fails and still consumes the turn.

05

No repeated probing

Each player may attempt each mystery cell at most once. A player remembers its own attempted cells and whether each attempt succeeded.

06

Game ending is public

If a hypothetical hidden action would have ended the game but play continues, that hypothetical history is eliminated from the observer's information set.

07

True board decides victory

Three in a row on the underlying board wins even if some ownership is hidden from the opponent.

08

Strategies cannot use hidden truth

Every legal play strategy acts from its information set. Only the simulation-only Oracle benchmark sees the true state.
