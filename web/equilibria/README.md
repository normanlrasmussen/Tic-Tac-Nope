# Exact equilibrium artifacts

Generated sequence-form LP policies belong here.

An artifact is eligible to be labeled **Exact Nash (Sequence-Form LP)** only when it was produced from the complete unabstracted game and contains successful solves for both players plus a numerical value interval / duality gap.

The live website does not silently substitute MCCFR when an LP artifact is missing. Until a certified artifact is bundled for a configuration, Exact Nash remains an offline benchmark.
